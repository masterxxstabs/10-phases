# Changelog

Each version's notes become its GitHub Release text, and the first few lines
show on the in-game update card. Add a section here when you bump the version
in `ten_phases/__init__.py`.

## 1.4.0

- Go Fish multiplayer! Pick 10 PHASES or GO FISH in the lobby, then invite friends the same way
- Nearby games and the lobby show which game you're joining
- Everyone needs this version to play together online

## 1.3.0

- New game: Go Fish! Use the arrows on the main menu to switch between 10 Phases and Go Fish
- Go Fish has the same look, computer players from Easy to Expert, hints, and speech bubbles
- Every Go Fish book you make adds 5 chips to your Chip Bank

## 1.2.2

- Hint fixes: it now spots phases where two sets share a number (like 4444+W and 4+W)
- The Hint never tells you to discard a card you need for your phase
- "Take the discard" is only suggested when that card actually gets you closer

## 1.2.1

- Computer players now get random names from a pool of 70, so every game has a different cast

## 1.2.0

- Hover over any player to see their phase, cards on the table, chips and recent moves
- Easier-to-read pixel text with a new bundled pixel font
- Chips you finish a game with are saved to your Chip Bank on the main menu

## 1.1.0

- The game now updates itself: new versions download in the background and install with one click
- Your version number shows on the main menu and in Settings
- Multiplayer tells you when you and the host are on different versions
- New Settings option to turn automatic updates off

## 1.0.0

- First release: Phase 10-style card game with Easy to Expert computer players
- Handheld-style table, sound effects and a Customize screen
- Multiplayer with invite codes and nearby games
