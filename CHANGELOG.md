# Changelog

Each version's notes become its GitHub Release text, and the first few lines
show on the in-game update card. Add a section here when you bump the version
in `ten_phases/__init__.py`.

## 1.1.0

- The game now updates itself: new versions download in the background and install with one click
- Your version number shows on the main menu and in Settings
- Multiplayer tells you when you and the host are on different versions
- New Settings option to turn automatic updates off

## 1.0.0

- First release: Phase 10-style card game with Easy to Expert computer players
- Handheld-style table, sound effects and a Customize screen
- Multiplayer with invite codes and nearby games
